# Contributing

Small, focused bug reports and pull requests are welcome.

## Privacy first

Never attach a real private conversation, browser profile, cookie, credential, patient record, or proprietary transcript. Reproduce capture problems with the smallest synthetic HTML or text fixture possible, and replace names, account identifiers, URLs, and local paths.

## Before opening a pull request

```powershell
npm test
npm run check
npm run audit:public
```

If an upstream ChatGPT, Grok, Claude, or Gemini DOM change is involved, describe the selector shape and expected role order without pasting private conversation content.
